### 01 — ROUTE / LIGHT / CHOICE

**[SmartBus →](https://github.com/SauravSunish/mini-project-sonajafy)**  
A bus-booking system that treats seat selection as a small spatial-computing problem. It combines route, journey time, and solar position to distinguish shaded seats from sunny ones—then carries the idea through booking, live tracking, QR tickets, and fleet administration.

`PHP` `MySQL` `JavaScript` `SunCalc`

> The interesting part was not “build a booking form.”  
> It was: **can the interface make a physically informed recommendation?**

### 02 — TOKENS / ATTENTION / EVIDENCE

**[BERT × SST-2 →](https://github.com/SauravSunish/AIpro)**  
A reproducible sentiment-classification experiment built around BERT fine-tuning and multi-head attention inspection. The project includes a CLI pipeline, evaluation, static visualizations, and an explicit warning against confusing attention with causal explanation.

`Python` `PyTorch` `Transformers` `NLP`

> A model output is a result.  
> A documented experiment is an argument.
